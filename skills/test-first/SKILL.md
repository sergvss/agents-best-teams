# Тест сначала

1. **Красный.** Один тест на одно поведение; имя называет поломку, которую он ловит.
2. **Проверь красный — обязательно.** Запусти: тест падает на проверке и по ожидаемой причине, а не ошибкой импорта или опечаткой. Упал не так — чини тест.
3. **Зелёный.** Минимальный код, после которого тест проходит.
4. **Весь набор проекта зелёный** — не один свой файл.
5. **Рефакторинг** — только при зелёных тестах.

**Баг** — первым делом тест, который воспроизводит его и падает на текущем коде. Исправление без такого теста не принимается.

**Код уже написан до теста** — не удаляй. Напиши тест, затем сломай проверяемое поведение (откати исправление): тест обязан покраснеть. Не покраснел — он ничего не проверяет. Верни код.

**Хороший тест** проверяет поведение, а не текст файла; настоящий код, а не мок; ожидаемое значение не вычисляется тем же кодом.

**В отчёте** — команда и вывод красного прогона и итог зелёного прогона всего набора.
